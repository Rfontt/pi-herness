# Planning

Produce a short, actionable plan BEFORE implementing, when the work is non-trivial.

## Plan format
1. Goal (1-2 sentences)
2. Relevant context (what you read in .ai/ or the code)
3. Steps (small, verifiable, ordered)
4. Risks/uncertainties
5. Acceptance criteria (how you know it's done)

## Rules
- Wait for approval before touching code.
- Small steps: each step must be verifiable in isolation.
- If you discover something new mid-execution, go back to the plan and adjust before continuing.
