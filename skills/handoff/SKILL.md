# Handoff

When closing a session, write a short handoff in .ai/context/handoff.md (or wherever indicated):

## Format
- Done: what was completed this session
- Failed/pending: what didn't work or was left open
- Next: the suggested next step
- Decisions/lessons: pointers to .ai/ (if any)

## Goal
Allow continuing in another session (or another agent) WITHOUT re-explaining the context.
